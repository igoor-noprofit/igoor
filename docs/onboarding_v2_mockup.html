Key change vs. today: onboarding no longer requires an AI provider. The API key moves from "mandatory at the door" to "optional, connect anytime" (Settings → AI, or the empty-state card in the main view). Key dependency: the offline ASR default is language-bound — a language must be known before the sherpa-onnx small model can be selected/downloaded. Every shipped language has a local model (dedicated zipformer / Whisper / NeMo models for en, fr, it, ko, pt, zh); any other language falls back to the multilingual Whisper-tiny model — so ASR is never unavailable, only dedicated vs. generic.

3 · Design notes & open questions

1Merge "loading" and "choice"

Don't dead-end on a progress screen. Show the choice screen as soon as the backend answers, with the boot bar pinned at the top (same visual as the header). Only Import waits for 100% — new-profile fields can be filled while plugins load.

2Language picks the offline ASR model

Every shipped language has a local model — catalog: en/fr (zipformer), it (Whisper), pt (NeMo), plus ko/zh and a multilingual Whisper-tiny fallback for anything else. What varies is model type, size (42–136 MB "small") and accuracy: the ASR step should say "dedicated vs. generic model", never "unavailable".

3Name & health are skippable

The very first screens may be navigated by an uncalibrated eye-tracker or by a caregiver. Every field is big-target, optional and editable later. Consider a calm "do this with a caregiver" sub-caption.

4Model download is a first-class step

25–125 MB on first run: show size, allow skip, never block (offline / metered connections). The download can also continue in the background after the user enters the app.

5Import failure & restart are part of the flow

Bad ZIP / version / embedding-model mismatch all need a designed state with a clear way out (retry, other file, or start new). A successful import ends with an explicit restart step.

6Keyless main view needs an explicit "AI off" state

Today the Flow panel would just fail silently. Replace with the empty-state card shown in screen 8 — one click to Settings → AI. Free typing → TTS already works with no key.

7Accessibility bar

IGOOR rules: big buttons, minimal clicks, outline icons only (Phosphor light). The choice screen is the single most important screen of the product — two giant targets, nothing else competing.

8Existing users never see this

First-run = a persisted flag; users upgrading from a completed setup are grandfathered in silently. The current "force onboarding" action remains for support.
